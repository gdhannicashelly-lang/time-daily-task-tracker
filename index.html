Installation Guide

Follow the instructions for your device to add the app to your home screen or desktop.

Android Devices

Install the app using Google Chrome.

  1. Open your app link in Chrome.
  2. Tap the three-dot menu.
  3. Select Install app or Add to Home screen.
  4. Follow the installation instructions.

iPhone & iPad

Add the app to your Apple device using Safari.

  1. Open your app link in Safari.
  2. Tap the Share button.
  3. Select Add to Home Screen.
  4. Tap Add to finish.

Windows & Desktop

Use your preferred supported browser.

  1. Open your app link in Chrome or Edge.
  2. Look for the install icon in the address bar or browser menu.
  3. Select Install App.
  4. Launch it from your desktop or Start menu.
